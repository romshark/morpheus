## Open Alpha

- **Pre-v1** APIs (component names, attributes, events, CSS variables, etc.) are subject to change. Before the **v1.0.0** release, no backward compatibility guarantee is provided. API change suggestions and feature requests are welcome in [GitHub issues](https://github.com/romshark/morpheus/issues). PRs are welcome but should generally be preceded by a discussion in the issues. (see [CONTRIBUTING.md](https://github.com/romshark/morpheus/blob/main/CONTRIBUTING.md)).
- **Components are manually tested** before being released. Yet bugs may still be hiding and we kindly ask you to [report them via GitHub issues](https://github.com/romshark/morpheus/issues).
- **We provide best effort support.** Commercial support is currently not available.

On our way towards **a stable v1.0.0 release** we aim for a feature-complete, fully documented and battle-tested implementation with optimal performance and modular, size-optimized bundles.

## How to help

UI systems are notoriously hard to test. Even though the components have already undergone extensive manual testing across keyboard/mouse and touch devices on major browsers (latest versions of Safari, Firefox and Chromium-based browsers), we still need more hands-on testing. The best way to help us is to battle-test Morpheus and report any issues you encounter via [GitHub issues](https://github.com/romshark/morpheus/issues).

## AI Use

AI tools were used to help make this project possible but the final product reflects our craft and creative vision. We value your time and hence provide the following quality guarantees:

- All design decisions are made by core contributors while AI tools are used to accelerate development only.
- Components are manually tested before being released. Tests are conducted for keyboard/mouse and touch devices on major browsers (latest versions of Safari, Firefox and Chromium-based browsers). AI is not used for quality control.
- The most critical pieces of documentation are carefully hand-written.
- AI generated and AI-assisted documentation and code are reviewed by core contributors on a best-effort basis and will be reviewed fully for the stable v1.0.0 release.

AI-assisted contributions are generally welcome under a few constraints:

- Issues and pull requests must be reviewed and understood by the person(s) submitting them.
- Contributions from automated systems acting on their own, and unreviewed AI-generated contributions, will be declined.
