Mask: Arabic-Indic and Persian digits

Arabic and Persian keyboards type Arabic-Indic (U+0660-0669) or Persian (U+06F0-06F9) digits. isDigit in web/lib/mask.ts takes only ASCII 0-9. A # slot in <neo-textinput mask> and <neo-otp> drops them, and so do numeric-only and format="number", which also strips [^\d.-]. The fix maps them to ASCII digits before the test.

  1. Click Run. Each case types the same digits into 2 identical fields, ASCII on the left and Arabic-Indic or Persian on the right, then compares their values.
  2. Each row should read PASS. Before the fix, the right field stays empty.
  3. To check real input, switch the keyboard to Arabic or Persian and type into the last field, or copy a string from the table and paste it.

typed sends 1 insertText per char, as keystrokes do. pasted sends 1 insertFromPaste with the whole string. Both are synthetic beforeinput events. When the component doesn't cancel one, the page inserts the text and fires input, as the browser would.
