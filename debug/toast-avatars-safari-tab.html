Safari Tab order: neo-toast and neo-avatars

Safari's default Tab order skips a <button> without an explicit tabindex. The close button of <neo-toast> and the "+N" button <neo-avatars> creates for an overflow <template> with no element inside carry tabindex="0" for this reason, as <neo-button> does. Without it, Tab skips them.

From file:// the icons don't load, which leaves the toast close button a small square. To see them, run python3 -m http.server in the repo root and open http://localhost:8000/debug/toast-avatars-safari-tab.html.

  1. In Safari, keep Settings > Advanced > "Press Tab to highlight each item on a webpage" off, the default.
  2. Click into Before, then press Tab until focus reaches After.

Each row shows its Tab stop or "skipped". Every row but the native <button> must get a stop. The native <button> row must be skipped, otherwise the setting is on.
