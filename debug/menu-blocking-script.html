neo-menu: empty menu with a blocking script

This page loads bundle.js as a blocking script in the <head>, which defines <neo-menu> before the parser reaches it. Its connect then runs at the start tag, before any row exists, and the rows parsed after that land beside its panel. <neo-menu> and <neo-submenu> move them into the panel. Without that, the menu opens empty and its rows render inside the button.

  2. Click File (inserted), the same menu inserted after parsing.
